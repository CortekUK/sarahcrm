The Club — Member Area Features

Member Feed

  • Post updates and photos
  • Like and comment on posts
  • Admin can pin, hide or remove posts

Groups

  • Every member automatically joins The Club main group
  • Interest groups (e.g. Travel, Collaborate, Meet-ups, Events)
  • Members join the groups they want and post inside them
  • Admin creates and manages groups

Direct Messages

  • Private one-to-one chat between members
  • Send text and photos
  • Block and report members
  • Admin can review reported conversations

Event Chats

  • Every event gets its own chat for attendees
  • Connect before the event, follow up after
  • Closes automatically after the event

Member Directory

  • Browse members with photo, role and company
  • Filter by industry and interests
  • Request an introduction from a profile

Notifications

  • New messages, comments and replies
  • Group and event updates

Later (Optional)

  • "I'm at the event" status so members can find each other
  • Live streaming
